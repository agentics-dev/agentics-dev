## ⚡ 快速通道 — 用 GPRM 重做這個主頁

想幾分鐘內換個風格？本頁就是一個 **GPRM** 版式：

1. 開啟 [**GitHub Profile README Maker**](https://gprm.rahuldkjain.github.io)，輸入使用者名稱 `agentics-dev`。
2. 在 **Add-ons** 勾選 *typing SVG*、*dynamic capsule-render（頁首/頁尾）*、*streak-stats*、*top-langs*、*github-stats*，再將本頁已用的徽章與卡片貼上。
3. 選一個主題（本頁使用 **tokyonight** + 靛藍→青色漸層），把產生的 Markdown 覆蓋到對應的 `README.md` / `README.zh-CN.md` / `README.zh-TW.md`。
