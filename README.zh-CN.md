## ⚡ 快速通道 — 用 GPRM 重做这个主页

想几分钟内换个风格？本页就是一个 **GPRM** 版式：

1. 打开 [**GitHub Profile README Maker**](https://gprm.rahuldkjain.github.io)，输入用户名 `agentics-dev`。
2. 在 **Add-ons** 中勾选 *typing SVG*、*dynamic capsule-render（页眉/页脚）*、*streak-stats*、*top-langs*、*github-stats*，再把本页已用的徽章与卡片粘贴进去。
3. 选一个主题（本页使用 **tokyonight** + 靛蓝→青色渐变），把生成的 Markdown 覆盖到对应的 `README.md` / `README.zh-CN.md` / `README.zh-TW.md`。
